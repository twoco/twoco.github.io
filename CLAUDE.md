# Règles pour Claude

Ce dépôt héberge le site twoco.github.io. Le propriétaire valide toutes les modifications lui-même.

## Règles obligatoires

- Toujours travailler sur une branche à part (préfixe `claude/`), jamais directement sur `main`.
- Ne jamais pousser (push) sur `main`.
- Toujours proposer les modifications via une pull request.
- Ne jamais merger une pull request : c'est toujours le propriétaire qui merge.
- Ne jamais modifier les réglages du dépôt ou de l'organisation (protection de branches, collaborateurs, etc.).
- Ne pousser une branche ou ouvrir une pull request que lorsque le propriétaire le demande.
- Communiquer en français.
